\# 🛒 ClickKart



ClickKart is a simple \*\*E-commerce Website\*\* built with \*\*HTML, CSS, JavaScript, Flask, and MongoDB\*\*.

It lets users browse products, log in, add to wishlist, and place orders (My Orders).



---



\## ✨ Features

\- 👤 User Authentication (Login \& Signup)

\- 🧭 Sidebar navigation (Home, Wishlist, Profile, Orders)

\- 📦 Browse products by category (Men, Women, Kids)

\- 🔎 Search with flexible tags (e.g., "mens jeans", "women saree")

\- ❤️ Wishlist

\- 🛍️ Place orders (stored in \*\*My Orders\*\*)

\- ⚙️ Backend: \*\*Flask + MongoDB\*\*



---



\## 🛠️ Tech Stack

\- \*\*Frontend\*\*: HTML, CSS, JavaScript

\- \*\*Backend\*\*: Python (Flask)

\- \*\*Database\*\*: MongoDB

\- \*\*Version Control\*\*: Git \& GitHub
